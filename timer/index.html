How to use it in class
  1. Open this page in Safari (not as a Home Screen icon) and set AirPlay to Screen Mirroring.
  2. Choose music on or off before you start. Switching it while the timer floats may close the floating window. If that happens, tap Start & float again.
  3. Set the time and tap Start & float. Then switch to PowerPoint or Notability. The timer stays on top.
  4. To change the time, come back to Safari and tap +/− or a quick button. The floating timer jumps straight away.
  5. The timer turns red for the last 10 seconds. The music changes for the last 41 seconds, and a chime plays at the end.
  6. To pause, tap the floating timer once and use its pause button. Drag it anywhere and pinch to resize it.
