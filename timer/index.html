⏱ Floating Class Timer

Pick a time, then tap Start & float. The timer pops out over PowerPoint or Notability.

How to use it in class
  1. Open this page in Safari (not as a Home Screen icon, because floating doesn't work there).
  2. In Control Centre, set AirPlay to Screen Mirroring so students can see the timer on the projector.
  3. Pick a time and tap Start & float, then swipe up or switch to PowerPoint or Notability. The timer stays on top.
  4. Drag the timer to any corner. Pinch to resize it. Tap it once for pause and close controls.
  5. Turn the iPad volume up so the chime can be heard at the end.
